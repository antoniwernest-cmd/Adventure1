READING ADVENTURES COLLECTION

Open index.html for the combined landing pad.

EIGHT ACTIVITIES
1. Sentence Adventures 1 - 100 scenes in each reading level.
2. Sentence Adventures 2 - 100 scenes in each reading level.
3. Before & After - 50 pictured scenarios in each reading level.
4. Pronoun Detective - 30 questions per level.
5. Homophone Harbour - 30 questions per level.
6. Paragraph Builder - 30 questions per level.
7. Meaning Master - 30 questions per level.
8. Letter Writing - 50 letters per level; arrange 3 sentences in A or 4 in AA.

All activities include Level A and Level AA. Use Landing pad inside an activity
to return to the combined landing page. View pictures browses all 284 story
illustrations, with filters for the eight activities.

NEW PICTURE IDS
The 20 school-supply choices have been replaced with small 3D animated objects
from the story pictures: watering can, sand bucket, kite, bird feeder, bicycle,
helmet, toy train, puzzle piece, carrot, envelope, paint palette, lunchbox,
plant pot, tent, telescope, paper plane, cupcake, seashell, robot and violin.
The same pictures are used across all eight activities. Choose the same picture
each time in an activity to return to its saved progress.

Existing internal profile identifiers are retained so existing records stay
attached to their profiles. PROFILE-IDS.json maps each former school-supply
picture to its replacement. Progress remains separate for each activity and
level. Progress is stored in this browser and website origin; moving to another
browser, device or website does not automatically transfer progress.

TEACHER VOICE AND REPORTS
Teacher voice on the landing pad controls all eight activities in this
collection. Teacher code: 259. The shared choice is saved for this browser.
Each activity retains its teacher tools, voice speeds, hints and Excel reports.
Before & After opens every picture on Before, including saved pictures and
reviews. Next opens After for the same picture; the next picture unlocks only
when both answers are correct.

DEPLOY THE WHOLE FOLDER
All required HTML, JavaScript, styles, pictures and picture IDs are included.
There is no build step or package installation. No ZIP is needed.

Upload the contents of Reading-Adventures-Collection to your static website
host. index.html must be at the published root. Keep all five activity folders
and the shared assets folder together. For a connected GitHub repository, use
this folder as the Netlify base directory (or put its contents at repository
root). netlify.toml publishes the current directory; leave build command empty.

ARTWORK AND CHECKS
The story illustrations and activity scripts are reused from the existing
projects. The 20 new picture-ID images were created with the built-in image
generation tool, using objects in those illustrations as references.
PROFILE-ARTWORK.json contains their prompts, references and file hashes.
picture-ids-preview.jpg shows all 20. CHECKS.json records link, image, script
and browser verification, including common laptop and tablet layouts.

LETTER WRITING
The greeting and sign-off are provided. Arrange the body sentences vertically
using the up/down buttons or drag grips, then check your letter. Next unlocks
when the order is correct. Listen reads your current arranged order. The 50
existing Before & After pictures are reused for both levels.
Letter Writing Excel assessments include completed letters only, with all
their earlier incorrect and correct attempts, attempt numbers and totals.
