LANGUAGE ADVENTURES

Open index.html for the landing pad.

FOUR ACTIVITIES
Pronoun Detective, Homophone Harbour, Paragraph Builder and Meaning Master.
Each has 30 tasks in version A and 30 in AA: 240 tasks altogether.
A uses shorter passages and three-sentence paragraphs. AA uses longer passages
and four-sentence paragraphs. AA paragraphs accept either order for the two
independent supporting details.
Spare sentences share the activity or setting, but do not support the paragraph's
specific main idea. A and AA have different spare sentences, with closer choices
in AA. PARAGRAPH-CONTENT.json records the main ideas and reasons for each choice.

PICTURES AND READING
All 34 story illustrations were made for this collection using the built-in
image generation tool. View pictures on the landing pad opens the gallery.
Use Previous / Next, the picture list, or the activity filter to browse.
Each activity also has Enlarge picture. On tablets and narrow screens,
Picture and Read & work give each view the full workspace.
The picture and reading areas share the screen on wider laptops.
ARTWORK.json records the complete prompt set and file hashes.
The cat, balloon and school-supply interface pictures are reused.

PROGRESS AND TEACHER TOOLS
Choose one school-supply picture and use it again to continue.
Progress is saved in the current browser on the current device.
Each question earns credit once. Reset question keeps earned credit and the
assessment history. Teacher tools exports Excel for one or all school supplies,
including responses, attempts, hints, listens, support and assessment type.

TEACHER VOICE
Open Teacher voice, enter 259, then choose Enable voice or Disable voice.
The setting applies to all four activities in this browser. It also controls
automatic reading when moving to another question. Voice uses the browser's
built-in speech service and the voices installed on that device.

DEPLOYMENT — NO BUILD REQUIRED
Keep this entire folder together, including every assets subfolder.
Use the CONTENTS of Language-Adventures as the site's root: index.html must
sit directly at the deployed root, beside activity.html and pictures.html.
For a GitHub-connected Netlify site, use this folder as the repository root,
or set Netlify's base directory to this folder's location in the repository.
Leave the build command blank and use . as the publish directory.
The included netlify.toml sets publish = ".".
There are no required CDNs, package installs, API keys or external image files.
Deploy the folder; no ZIP is needed.

If an older version is open, refresh the page to load the revised files.
