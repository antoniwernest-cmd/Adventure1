LETTER WRITING

Open this activity from the Reading Adventures Collection landing pad.
50 friendly letters in each reading level, reusing 50 existing story pictures.

A: organise exactly 3 body sentences vertically.
AA: organise exactly 4 body sentences vertically.
The greeting and sign-off are supplied outside the sortable body.

Use the up/down arrows or drag a grip to move a sentence. Check my letter
checks the complete order. Next letter unlocks only when the order is correct.
A large spinning check mark celebrates a correct letter in both levels.
The celebration stays still when the device requests reduced motion.
The invitation letter accepts multiple coherent orders for its details.
Listen reads the current arranged order. The shared teacher voice code is 259.

Use the same story-object picture ID to continue in this browser. Progress is
separate for A and AA. Start again preserves earned credit and assessment
history. Teacher tools include support, formative/summative assessment and
native Excel reports with Summary, Progress, Attempts and Guide worksheets.
Excel includes only letters with earned completion credit. For those letters,
every incorrect and correct check appears with its result and attempt number.
Totals include those attempts. Hints and listens are separate events.
Start again keeps earned completion credit and the attempt history.
Saved AA orders from the five-sentence version adapt to four sentences while
keeping earned credit and assessment history.

This folder uses pictures and shared files in the parent collection. Deploy
the whole Reading-Adventures-Collection folder. No build step or ZIP is needed.
